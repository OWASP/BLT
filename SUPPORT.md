# Getting Help

| You want to... | Go to |
|---|---|
| Report a bug or request a feature | [Open an issue](https://git.owaspblt.org/BLT/issues) on git.owaspblt.org. Name the project folder (for example `blt-leaf`) in the title or body. |
| Ask a question or discuss an idea | [Discussions](https://git.owaspblt.org/BLT/discussions) on git.owaspblt.org, or `#project-blt` on the [OWASP Slack](https://owasp.org/slack/invite) |
| Get help with an issue you're working on | Comment on that issue, or ask in `#project-blt` |
| Report a security vulnerability | **Not** an issue or Slack: follow [SECURITY.md](https://git.owaspblt.org/BLT/blob/SECURITY.md) |
| Report a conduct problem | Follow [CODE_OF_CONDUCT.md](https://git.owaspblt.org/BLT/blob/CODE_OF_CONDUCT.md) |
| Learn how to contribute | [CONTRIBUTING.md](https://git.owaspblt.org/BLT/blob/CONTRIBUTING.md) |
| Read the user and developer docs | [docs.owaspblt.org](https://docs.owaspblt.org/) and each project folder's README |

Before asking, search existing [issues](https://git.owaspblt.org/BLT/issues) and check the project's README.
When you ask, include the project, what you did, what you expected and what happened (logs, screenshots,
browser or OS). Never post secrets or tokens.

BLT is run by volunteers, so answers can take a few days. Please don't open issues or pull requests on the
read-only [GitHub mirror](https://github.com/OWASP/BLT); nobody watches them.
