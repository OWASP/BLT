How it's scored

Each project gets points for evidence that it has ended and loses points for evidence that it is alive. The points add up to a score from 0 to 100, which picks the suggestion: Archive at 70 or more, Mark inactive at 45, Ask leaders first at 25. Hover a score for its sum.

Against (adds points)

  • Idle: 15 points a year (up to 60) since the last commit by a person or the last release on the project's code repository. Bot commits (Dependabot, GitHub Actions…) don't count. The website repository (www-project-…) only counts when it is the project's only repository, because OWASP staff edit every project site in bulk.
  • Archived repository: 60 when the repository owasp.org links is archived on GitHub while the project is still listed (it ended, or moved and the link is stale).
  • Missing repository: 40 when it doesn't exist (404), 25 when owasp.org lists none.
  • Says it's finished: 30 when its description says deprecated, unmaintained, moved to…
  • Never set up: 20 when its owasp.org page is still the unedited www-project template.
  • Unanswered reminder: 20 for a Bumper reminder (or a hand-written "still maintained?" issue) open for a month with no reply, 10 for one closed without a reply.
  • Ignored contributions: 8 for three or more pull requests by people untouched for a year.

For (takes points away)

  • A commit in the last 90 days (−30), a release in the last year (−25), a maintainer's reply to a reminder (−15), and 1,000 or more stars (−10: widely used, so new leaders are worth looking for first).

Held back for review

  • Flagship and Production projects, and projects whose linked repository is archived while their website was edited this year, never go above Ask leaders first; the row says what the score alone would suggest.
  • Archive website repo: projects no longer in the owasp.org inventory whose www-project repository is still open and idle. Active, not listed: the same, with recent commits: worth asking whether they belong in the inventory.

Data

Refreshed daily: the owasp.org project inventory and each project's GitHub statistics from the OWASP Project Matrix; the last commit by a person, archived status, reminder issues and website templates from Bumper's own scan of the OWASP organization; open pull requests from the Matrix. For repositories outside the OWASP organization the last commit may be a bot's. Every suggestion is a starting point for a person to check, not a decision.
