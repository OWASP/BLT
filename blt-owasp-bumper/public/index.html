How it works

Every day Bumper lists the repositories in the OWASP GitHub organization with their last activity (the last commit by a person; bot commits don't count), type and language. Pick the idle ones with the filters, tick them (or Select all matching), then Open issue forms: each opens GitHub's new-issue form on that repository, prefilled with a short reminder asking a maintainer whether the project is still maintained. You review and submit each one, signed in as yourself.

Browsers allow only a few tabs per click, so forms open in batches of 10; click again for the next batch. If your browser blocks them, allow pop-ups for this site. Copy checklist copies the selection as a Markdown task list with each repository's reminder link, for a tracking issue or for working through later.

Best to bump (the default order) scores each repository as importance × staleness × noise. Importance counts stars, forks, open issues and pull requests, OWASP projects and their level, and stars arriving after the last push. Staleness grows with the years since the last commit by a person: bot commits (dependabot, GitHub Actions…) don't count as upkeep. Noise pushes down forks, templates, empty repositories, ones that say they moved or are defunct (archive them instead), "-old" copies, near-duplicate siblings, and repositories that already have an open reminder issue; the clearest cases are collapsed as Low-signal. Hover a score for the full breakdown; a short note under it flags what the other columns don't show (fork, moved, duplicate, PRs waiting…). The other orders are in the sort menu and the column headers.

Repositories you have opened a form for are remembered in this browser (Bumped by me). Archived repositories and ones with issues turned off can't be bumped. Last bump shows each repository's latest reminder issue (Bumper's own, and any titled "still maintained"): its age, whether it is still open, and its replies, with the last reply linked (hover for who and when). Filter with the Last bump menu: open, no reply yet, replied, closed, or never bumped. A repository whose reminder was opened less than a year ago links to it instead of offering a second one: follow up there.
