BLT-CVE Registry

A decentralized, federated, machine-readable vulnerability namespace for the OWASP BLT ecosystem, published as static JSON on Cloudflare.

View JSON feed Open schema
  • ID format BLT-YYYY-NNNN
  • Path /cves/YYYY/
  • Hosting static, server-free

BLT IDs are not MITRE-issued CVE IDs. They are community-assigned identifiers within the OWASP BLT ecosystem. Always cross-reference official CVE sources for production security decisions.
