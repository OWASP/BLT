How it works

Three steps to erase your footprint

Vanish keeps everything on-device. No accounts, no servers, no tracking of the tracker.

01

Build your profile

Enter your name, email, and identifiers once. Vanish encrypts the profile with AES-256 and keeps it entirely in your browser — nothing is sent to a server.

02

Queue broker removals

Select from the pre-built broker list — Whitepages, Spokeo, Intelius, and more. Vanish generates the correct opt-out request for each and tracks the expected response date.

03

Monitor new mentions

The built-in monitor checks for fresh references to your identifiers across data brokers and surfaces them in the dashboard so you can act before they spread further.

Vanish modules

Start with the module your privacy workflow needs.

Each module runs locally. Cards link to the docs so you can read the implementation before you run anything.

/ephemeral-logs

Create and expire time-bound activity logs that auto-purge after a configurable TTL.

 /auto-scrub

Strip PII from stored records on a schedule — names, emails, phone numbers, and addresses.

 /broker-queue

Manage pending opt-out requests, check response deadlines, and mark removals confirmed.

 /privacy-settings

Configure encryption keys, scrub schedules, and identifier sensitivity levels.

 /monitor

Watch for new mentions of your identifiers across data brokers and flag them for action.

 /profile-export

Download your encrypted local profile as a portable file for backup or device transfer.

Setup

Three ways to run Vanish.

Pick the option that fits your workflow. All three keep your data on your device.

Option 1

Web app

Use the browser version directly for a local-first workflow.

  1. Scroll up to the App section
  2. Create a new privacy profile
  3. Enter your information and keep it on your device
  4. Review data brokers and opt-out instructions
  5. Download your encrypted profile for safekeeping

Your data never leaves your browser.

Option 2

Native app

Install the full Flutter application from releases.

  1. Visit the GitHub Releases page
  2. Download the build for your platform:
    • .exe Windows
    • .dmg macOS
    • .AppImage Linux
    • .apk Android
  3. Install and run the application
  4. Follow the in-app setup wizard

Option 3

Build from source

For developers who want to build locally.

# Clone the repository
git clone https://gitlab.com/owasp-blt/blt-vanish.git
cd BLT-Vanish-Web

# Install Flutter dependencies
cd flutter_app
flutter pub get

# Run on your platform
flutter run -d windows

See CONTRIBUTING.md for the full build guide.
