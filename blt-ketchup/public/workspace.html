Summary

The login endpoint at /api/v1/auth/login is vulnerable to classic SQL injection via the username parameter. An unauthenticated attacker can bypass authentication or dump the entire user database by submitting a crafted payload.

Steps to Reproduce

  1. Navigate to https://acme-corp.example.com/login
  2. Enter ' OR '1'='1 as the username
  3. Enter any password
  4. Observe that authentication is bypassed
  5. Use sqlmap to enumerate the full database schema

Impact

Full authentication bypass and potential for complete database exfiltration including PII, credentials, and session tokens for all 14,000+ users.

Remediation

Use parameterized queries (prepared statements) for all database interactions. Implement input validation. Enable a WAF rule for SQLi patterns as a short-term mitigation.
