Why BLT?

Everything you need to hunt bugs

A full-featured, open-source bug reporting platform built for security researchers, developers, and anyone who wants a better internet.

Report Any Bug

Capture and report any type of issue — from broken UI to critical security vulnerabilities — directly from your phone.

Earn Points & Rewards

Every valid bug you report earns you points. Climb the leaderboard and get recognised by companies and the security community.

Bug Hunt Programs

Organisations can launch bug hunt programs with prize pools, giving hunters incentive to find every possible issue.

OWASP Backed

Developed under the OWASP umbrella, BLT follows rigorous security standards and best practices.

Community Driven

A global community of bug hunters and security researchers collaborating to make the web safer for everyone.

Fully Open Source

Every line of code is open source. Contribute, audit, and improve the platform in the open.
