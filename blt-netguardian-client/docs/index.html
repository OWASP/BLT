Features

Everything you need to orchestrate comprehensive security monitoring.

Task Queue Management

Queue, monitor, and deduplicate security scanning tasks across all agents and target types.

Target Registration

Register and manage scan targets: websites, smart contracts, APIs, and code repositories.

Multi-Agent Support

Coordinate Web2 crawlers, Web3 monitors, static analyzers, contract scanners, and volunteer agents.

Vulnerability Dashboard

View, filter, and triage discovered vulnerabilities by severity, target, agent, or status.

Real-time Job State

Track task states with live updates via Cloudflare Worker API polling and push notifications.

Cloudflare Worker Backend

All data flows through Cloudflare Worker API endpoints — scalable, serverless, and globally distributed.

How It Works

From target registration to vulnerability report in four steps.

  1. 1

    Register a Target

    Add the URL, contract address, or repo path you want to monitor.

  2. 2

    Queue a Task

    Select an agent type and priority, then push the task to the Cloudflare Worker queue.

  3. 3

    Agents Scan

    Distributed agents pick up tasks and ingest results back into the platform automatically.

  4. 4

    Triage Results

    Review the vulnerability dashboard, filter by severity, and export findings to BLT.

Configure

Set your Cloudflare Worker endpoint and preferences before running the app.

API Configuration

The base URL of your deployed Cloudflare Worker.

Environment Variables

# .env (placed next to main.dart)
WORKER_BASE_URL=https://your-worker.workers.dev
DEFAULT_AGENT_TYPE=web2
SCAN_TIMEOUT_SECONDS=30
DEDUP_ENABLED=true

Never commit your .env file. Add it to .gitignore before your first push.

Supported Agent Types

web2 web3 static contract volunteer

Architecture

Client-side Flutter app communicating with a serverless Cloudflare Worker backend.

Task Queue

  • POST /api/tasks/queue
  • GET /api/tasks
  • GET /api/tasks/:id

Target Registration

  • POST /api/targets/register
  • GET /api/targets
  • DELETE /api/targets/:id

Agent Results

  • POST /api/results/ingest
  • GET /api/results
  • GET /api/results/:id

Install & Build

Build and run the client for any platform Flutter supports.

Prerequisites

  • Flutter SDK 3.0.0 or later — Install Flutter
  • Dart SDK 3.0.0 or later (bundled with Flutter)
  • A running BLT NetGuardian Cloudflare Worker API endpoint
  • For Android builds: Android Studio / Android SDK
  • For iOS builds: Xcode on macOS

Quick Start

git clone https://github.com/OWASP-BLT/BLT-NetGuardian-Client.git
cd BLT-NetGuardian-Client
flutter pub get
flutter run

Build a release IPA for iOS distribution or TestFlight.

# Install dependencies
flutter pub get

# Release build (requires macOS + Xcode)
flutter build ios --release

# Archive for App Store / TestFlight via Xcode
open ios/Runner.xcworkspace

Build a release APK or App Bundle for Android distribution.

# Release APK (sideload)
flutter build apk --release
# Output: build/app/outputs/flutter-apk/app-release.apk

# App Bundle (Google Play)
flutter build appbundle --release

Build a production-ready web bundle and serve it from any static host.

# Build the web app
flutter build web --release
# Output: build/web/

# Serve locally
cd build/web && python3 -m http.server 8080

Build a native desktop executable for Windows, macOS, or Linux.

# Windows
flutter build windows --release

# macOS (requires macOS host)
flutter build macos --release

# Linux
flutter build linux --release
