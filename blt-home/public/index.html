    Why OWASP BLT

    Public bug reports, private disclosure and real recognition, built in the open by the OWASP community.

    Bugs loggedPublic bug reports

    Report 404s, broken flows, typos and design bugs on any site. Reports are public, so anyone can follow the fix. See reports

    Zero-trust disclosure

    BLT-Zero delivers vulnerability reports as encrypted payloads, with no analytics or tracking and only minimal metadata kept. Open BLT-Zero

        Explore BLT

        One core project, many tools around it: reporting and disclosure, community and rewards, developer tools and learning. Every card opens a live site.

        • BLT-NextThe next-generation BLT web app, in development.

        • BLT-ZeroEncrypted, zero-trust vulnerability disclosure.
        • BLT-ExtensionCapture a page and report a bug from your browser.
        • BLT-FlutterThe BLT app for phones and desktops.
        • BLT-CVEA verifiable, machine-readable vulnerability registry.
        • BLT-ToastyAI triage and responsible-disclosure assistant.
        • BLT-NetGuardianSigned findings, domain crawls and org triage.

        Get involved

        Build BLT with us

        Every BLT project lives in one repository on git.owaspblt.org. Pick an issue, say hello on Slack, and send a pull request.

        • Hacktoberfest issues

          Scoped issues with acceptance criteria and test steps. Comment /assign to claim one.

        • Good first issues

          Small, well-described tasks for your first BLT contribution.

        • Source on git.owaspblt.org

          The BLT monorepo: every project, one clone. open issues right now.

        • AI policy

          How to use AI tools when you contribute, and what to disclose.

        • #project-blt on OWASP Slack

          Ask questions and meet maintainers. Join OWASP Slack first if you are new.

        • Google Summer of Code

          OWASP BLT mentors GSoC students. See the project ideas and how to apply.
