Vanish is an open-source Flutter app that finds data brokers holding your personal information and helps you send opt-out requests—entirely from your device, with zero data leaving it.

Everything you need to
erase yourself

Built ground-up for privacy. Vanish puts you in control with a clean, accessible Flutter interface that never compromises on security.

AES-256 Encryption

Every field of your personal data is encrypted with AES-256-CBC before being written to disk. Keys live in the platform's secure enclave (Keychain / KeyStore).

No External Servers

Your PII never leaves your device. Broker metadata is fetched from public sources only; the actual opt-out requests are generated locally.

Cross-Platform

One codebase for iOS, Android, macOS, Windows, and Linux. Flutter's widget engine delivers a pixel-perfect native experience everywhere.

Data Broker Directory

Browse a curated, searchable directory of data brokers. Filter by category and see opt-out methods & estimated response times.

Request Tracking

Track every opt-out request from submission to completion. Dashboard stats show total, completed, and pending requests at a glance.

Open Source

AGPL-3.0 licensed. Every line of code is on GitHub — fully auditable, forkable, and community-driven under the OWASP BLT umbrella.

Clean, accessible UI

How it works

Three simple steps to start erasing your data from the web.

  1. 1

    Set Up Your Profile

    Enter your name, email, phone, and address. Every field is immediately encrypted with AES-256 before it touches storage.

  2. 2

    Browse Data Brokers

    Search a curated directory of data brokers — filtered by category, opt-out method, and estimated response time.

  3. 3

    Send & Track Requests

    Submit opt-out requests and track their status from pending to completed — all from within the app, all stored locally.

Security Architecture

Built security-first,
not security-last

Most apps encrypt data in transit. Vanish encrypts data at rest, at creation, and never transmits it at all. Here's how:

  • Secure Key Storage

    Encryption keys are stored in the platform's trusted enclave — Apple Keychain on iOS/macOS, Android KeyStore on Android.

  • Random IVs per Encryption

    A fresh random initialization vector is generated for every encryption operation, preventing pattern analysis even when values repeat.

  • Zero Telemetry

    No analytics SDKs. No crash reporting that phones home. No feature flags fetched from a server. Nothing.

  • Open & Auditable

    Every line of code is on GitHub under AGPL-3.0. Anyone can audit, fork, or contribute.

Get started in minutes

Flutter and Dart are the only prerequisites. Clone the repo and you're running.

  1. 1

    Install Flutter ≥ 3.0

    flutter.dev/get-started
  2. 2

    Clone & install dependencies

    $ git clone https://github.com/OWASP-BLT/BLT-Vanish-Flutter
    $ cd BLT-Vanish-Flutter && flutter pub get
  3. 3

    Generate code & run

    $ flutter pub run build_runner build
    $ flutter run

Build for every platform
