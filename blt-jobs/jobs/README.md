# Job listings (Markdown)

Each job is one Markdown file with YAML frontmatter. Filename format: `company-slug-job-title-slug.md` (e.g. `acme-senior-engineer.md`).

See the [Add a job](../../add.html) page for how to add a listing through a reviewable GitLab issue or Markdown change. A public job URL can help create a draft, but publication still goes through maintainer review.

Accepted listings are public Git data. Use external application URLs or intentionally public contact emails only.
