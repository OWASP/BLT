Seeker profiles live in this directory, one Markdown file per profile.

Filename format: `name-slug.md` (e.g. `jane-doe.md`).

Profiles may include `github`, `gitlab`, or both so seekers can link the source hosting platforms they use.

Each file has YAML frontmatter plus a Markdown body for the detailed “about” text.

Accepted profiles are public Git data. Only include email addresses, resume links, and contact routes that should be visible in the repository and static site.
