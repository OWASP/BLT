How It Works

Open-source hiring in three steps.

BLT Jobs keeps the workflow visible: proposals happen in Git, listings are stored as Markdown, and the public site is generated from reviewed open data.

01

Propose in Git

Open a GitLab issue, paste a public job URL, or propose a Markdown change. Every listing starts as a traceable submission.

02

Review as Markdown

Maintainers check the public fields, application route, and source context before accepting anything into the repository.

03

Publish open data

CI builds static JSON from accepted Markdown, and each public page can link back to its source file, issue, or Git history.
