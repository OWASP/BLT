About These Logos

The current canonical project artwork comes from blt-logo.vercel.app. Every imported PNG is normalized to a 512×512 transparent canvas and displayed in the same 112×112 presentation size. Projects not yet included in that collection retain their existing scalable SVG mark.

Usage Guidelines

Color Scheme: All logos use a consistent red gradient (#DC2626 to #991B1B) that aligns with OWASP-BLT brand identity.

Canonical source: blt-logo.vercel.app

Format: Canonical PNG files use a uniform 512×512 transparent canvas; legacy project marks remain available as SVG.

Location: Canonical logos are in docs/assets/img/canonical-logos/.

Attribution: Please maintain proper attribution to OWASP-BLT when using these logos.
