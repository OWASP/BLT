<!-- Theme before first paint (saved choice, else the system preference), then the shared top bar -->
<script>
  (function () {
    var saved = null;
    try { saved = localStorage.getItem("theme"); } catch (e) {}
    var dark = saved === "dark" || (saved !== "light" && matchMedia("(prefers-color-scheme: dark)").matches);
    document.documentElement.classList.toggle("dark", dark);
  })();
</script>

Do

  • Use class `dark` on html and localStorage `theme` for dark mode, and let the OWASP BLT top bar own the toggle.
  • Keep dark borders subdued: gray-800.
  • Use variables for cross-page surfaces and focus states.

Do Not

  • Use white borders or pure black surfaces in dark mode.
  • Mix unrelated reds with `#dc2626` and `#b91c1c`.
  • Create page-local theme variables unless the shared file cannot be used.
  • Load web fonts; BLT uses the system font stacks.
