BLT CSS Reference

The shared library file is `docs/assets/css/blt-design.css`. Product pages can copy this smaller token block when they do not consume the full guide CSS.

Do

  • Use `blt-theme` for persisted dark mode.
  • Keep dark borders subdued and slate-based.
  • Use variables for cross-page surfaces and focus states.

Do Not

  • Use white borders or pure black surfaces in dark mode.
  • Mix unrelated reds with `#E10101` and `#B91C1C`.
  • Create page-local theme variables unless the shared file cannot be used.
