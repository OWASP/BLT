Foundations

Typography

BLT uses Manrope for product UI and JetBrains Mono for code. Keep headings tight, body copy readable, and compact UI labels scannable.

Heading 1

text-5xl font-extrabold tracking-tight

Heading 2

text-4xl font-extrabold tracking-tight

Heading 3

text-2xl font-bold tracking-tight

Body text should sit at `text-base leading-7` for docs and longer explanations. Compact panels can use `text-sm leading-6`, but avoid dense paragraphs below that size.

Headings

Use `font-extrabold` for page titles and `font-bold` for card headings. Keep tracking at default or `tracking-tight` only for display text.

Labels

Small labels use uppercase only when they are section markers. Avoid uppercase for long phrases.

Code

Code blocks use dark surfaces in both themes for stable contrast and easier copying.

Snippet

<h1 class="text-4xl font-extrabold tracking-tight sm:text-5xl">Page title</h1>
<p class="mt-3 text-base leading-7 text-slate-600">Readable product copy.</p>
