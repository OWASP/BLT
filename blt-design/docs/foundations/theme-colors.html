Theme Colors

Use semantic tokens first. Direct Tailwind colors are acceptable in snippets only when they map cleanly to these BLT values.

Primary

#DC2626 · red-600

Primary action, active nav, focused brand states. Same red as owaspblt.org.

Primary Hover

#B91C1C · red-700

Button hover and active destructive emphasis.

Dark Accent

#EF4444 / #F87171 · red-500 / red-400

Red text, icons and focus rings in dark mode.

Active Accent

#FEF2F2 · red-50

Light chips, active sidebar items, icon wells.

Light Background

#F9FAFB · gray-50

Page background in light mode.

Light Surface

#FFFFFF · white

Cards, nav, panels, and input surfaces.

Light Border

#E5E7EB · gray-200

Subtle structure without heavy outlines.

Dark Base

#030712 · gray-950

Dark page background.

Dark Surface

#111827 · gray-900

Dark cards, sidebars, and panels.

Dark Border

#1F2937 · gray-800

Quiet dark border. Avoid white outlines.

Usage rules

  • Use red for intent, active states, and focus. Do not make whole pages red.
  • Surfaces are neutral Tailwind grays: white / gray-50 in light mode, gray-950 page and gray-900 cards with gray-800 borders in dark mode. Never use white borders in dark mode.
  • Keep text contrast high: headings on `--blt-text`, supporting copy on `--blt-text-muted`. In dark mode, red text uses red-400/500.
  • Cards are rounded-2xl with a gray-200 (light) / gray-800 (dark) border. Use red-50 only as a soft active/accent surface in light mode.
