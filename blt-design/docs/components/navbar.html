Components

Navbar

Every BLT site has one header: the shared OWASP BLT bar. A site does not build its own navbar; it configures the bar with its project, its links and its buttons.

Contribute

One header

The OWASP BLT brand, then the project's round symbol and short name, the project's own links in the centre, its buttons on the right, the apps chooser and the theme toggle. When they don't fit, and on phones, everything goes into the bar's menu, the project's links first. A live BLT-Zero bar:

Configuration

Attribute or childWhat it does
project="blt-x"The project's slug (its directory name). Its round symbol is owaspblt.org/_home/symbols/blt-x.svg.
name="X"Short name next to the symbol, without "BLT-" or "OWASP-" (Zero, Jobs, NetGuardian). Keep it to about 11 characters so it fits on a 375px phone.
home="/"Where the project's symbol and name link to; set it when the site lives under a sub-path.
current="auto"Marks the link to this page. Sites that already know the current page put aria-current="page" on that link instead; aria-current="false" keeps a link unmarked.
data-stickyKeeps the bar at the top while scrolling. Sticky sidebars then use top: 62px and height: calc(100vh - 62px).
data-theme-key, data-theme-attrFor sites whose dark mode uses another localStorage key or an attribute such as data-theme. The bar's toggle sets class dark on <html> and fires blt-theme-change.
<a> / <button> childrenThe site's links, in the centre (2 to 6). No classes needed: the bar styles them. Ids, data-*, click handlers and hidden keep working, so signed-in and signed-out buttons can toggle.
slot="actions"Buttons on the right: Login, Admin, the signed-in user. At most two or three.
data-primaryThe red call-to-action button: Contribute, Sign up, Submit, Report Bug. One per site.

Do

  • Put <blt-nav> first in <body>, even with no links (then the centre keeps the OWASP BLT links).
  • Keep page titles, breadcrumbs, search fields and toolbars in the page content.
  • App pages can keep an in-app sidebar under the bar.

Don't

  • Add a second header row under the bar with the project's logo, name or links.
  • Add a separate mobile menu button or another theme toggle: the bar has both.
  • Show a second wasp: the bar shows the OWASP BLT mark and the project's own symbol.
