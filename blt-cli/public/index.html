What it is

blt-cli is a terminal user interface client for the OWASP Bug Logging Tool (BLT) ecosystem, built in Rust with Ratatui and Crossterm. It gives developers keyboard-driven dashboards for triaging issues, tracking bounty hunts, viewing statistics and working with the BLT-MCP server.

Standalone mode

Connects directly to the REST endpoints of the BLT API (default https://api.owaspblt.org).

MCP mode

Acts as an MCP host, spawning the Python blt-mcp server in a subprocess to invoke its protocol tools.

Features

Tabs for Issues, Active Hunts, BLT Stats, Logs & Events and Settings.

Ecosystem dashboards

Tab-based views for browsing issues, hunts, statistics, logs and configuration.

Interactive triage

Update issue statuses with human-in-the-loop safeguards while network calls run in the background.

Bulk triage

Select several issues at once and move them to Open, In Review or Resolved in one step.

Search and filter

Filter issues and hunts instantly with an inline, interactive search overlay.

Audit and event log

A Logs & Events tab tracks agent and human actions and background syncs. State persists across restarts and exports to blt_export.log.

Vulnerability submission

Submit new vulnerability reports from an interactive multi-field form, pre-filled when launched from a hunt.

Bounty hunts hub

Browse active bug bounty hunts with their rules and rewards, then report against a specific target.

Leaderboard

See the top contributors and their accrued bacon in the statistics dashboard.

AI-assisted triage

Run an MCP analysis tool on a vulnerability for real-time suggestions and duplicate checks.

Build and run

Requires Rust and Cargo, installed with rustup.rs. The crate lives in the blt-cli folder of the BLT monorepo.

Quick start

$ git clone https://git.owaspblt.org/BLT.git
$ cd blt-cli
$ cargo run --release

# Optional API override
$ cargo run --release -- --api-base https://api.owaspblt.org

Checks and release build

# Formatting and clippy static analysis
$ cargo fmt --check
$ cargo clippy -- -D warnings

# Tests
$ cargo test

# Optimized release binary
$ cargo build --release

The binary is written to ./target/release/blt-cli (blt-cli.exe on Windows).

Flags and options

Values can also come from the environment or a local .env file.

# Spawn the Python MCP server subprocess to invoke protocol tools
$ blt-cli --mcp-path ../blt_mcp/server.py

# Query a custom or staging BLT REST API base
$ blt-cli --api-base https://staging.owaspblt.org

Keyboard shortcuts

Press h or ? inside the app for the quick legend.

KeyAction
Tab / Shift+TabMove between tabs or form fields.
1 – 5Jump to Issues, Active Hunts, BLT Stats, Logs & Events, Settings.
↑ / ↓, k / jScroll lists.
/Open the search and filter overlay.
SpaceSelect or deselect an issue for bulk triage.
tTriage the selected issue (or the bulk selection).
sOpen the Submit Vulnerability form (pre-filled from Hunt Details).
aRun AI-assisted MCP analysis on the selected vulnerability.
eExport the session log to blt_export.log (Logs & Events tab).
EnterConfirm a modal or open details, such as Hunt Details.
EscDismiss popups, modals and forms.
h / ?Toggle the help overlay.
q / Ctrl+CQuit and restore the terminal.
