BLT CLI

Triage issues, explore hunts and statistics, submit vulnerabilities, and run AI-assisted analysis from a fast Ratatui terminal interface.

Source code on GitLabAll BLT projects

Build and run

$ git clone https://git.owaspblt.org/BLT.git
$ cd blt-cli
$ cargo run --release

# Optional API override
$ cargo run --release -- --api-base https://api.owaspblt.org
