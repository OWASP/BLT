How it works

A simple path from issue to recognized contribution

BLT contribution events give contributors a focused window, maintainers a clear leaderboard, and the community a public record of useful work.

01

Pick an event

Choose an active or upcoming event, review its rules, and follow the linked repository guidance.

02

Contribute work

Submit issues, pull requests, reviews, and fixes during the event window so generated summaries can count them.

03

Track progress

Open the event dashboard to see participant totals, repositories, merged PRs, and leaderboard movement.

GSoC warmup

Practice before mentoring season begins

Warmup events help contributors build a visible history before Google Summer of Code style programs. They are useful for learning the BLT codebase, proving follow-through, and getting comfortable with review cycles.

Onboarding signal

Show steady activity before formal proposal periods.

Review practice

Learn how maintainers expect issues, PRs, and discussions to move.

Security context

Work inside OWASP BLT projects while learning responsible contribution norms.

Visible record

Generated summaries keep contribution activity easy to inspect.
