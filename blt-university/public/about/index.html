About BLT University

Open-source security courses and browser labs maintained by the OWASP BLT community.

Our Mission

BLT University is an open-source site for learning cybersecurity through short lessons, safe browser labs, and community-reviewed content.

Courses and labs live in the repository, so learners can see how the material changes and contributors can improve it through merge requests.

How It Works

Open Source

All courses are version-controlled and transparent, making curriculum changes easy to inspect.

Collaborative Teaching

Instructors update curriculum via merge requests, enabling community peer review.

Automated Workflows

Open automation handles enrollment and certificate generation consistently.

Community-Driven

Practitioners and students build and maintain practical learning paths together.

Our Core Values

  • Open Source Content is open and free to modify under AGPL-3.0.
  • Practical Learning Focused on real-world, hands-on security skills.
