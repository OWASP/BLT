KEY QUALITY FEATURES
================================================================================

HALLUCINATION PREVENTION
- Similarity thresholds: Only >0.6 similarity accepted
- Metadata validation: All chunks must have complete source info
- Content quality: Minimum chunk length enforced (50 chars)
- Fallback mechanism: Returns "no_match" vs making up answers
- Verified: 4/4 nonsense queries properly rejected

RETRIEVAL QUALITY
- Composite scoring: similarity (60%) + content (20%) + metadata (20%)
- Multi-pass filtering: Retrieves k*3 candidates, filters to top-k
- Quality levels: high (>0.75) / medium (0.6-0.75) / low (<0.6)
- Source attribution: Every result links back to OWASP source
- Metadata completeness: title, category, source_url, filename, chunk_index

HOW TO USE
================================================================================

QUICK START (DOCKER - RECOMMENDED)
  docker-compose build preflight-server
  docker-compose up preflight-server
  curl http://localhost:8000/health

NATIVE SETUP (LINUX/MACOS)
  bash setup.sh
  source .venv/bin/activate
  PYTHONPATH=src python -m uvicorn src.main:app --port 8000

NATIVE SETUP (WINDOWS)
  setup.bat
  venv\Scripts\activate.bat
  python -m uvicorn src.main:app --port 8000

TEST THE SYSTEM
  # Health check
  curl http://localhost:8000/health

  # Retrieve security guidance
  curl -X POST http://localhost:8000/retrieve \
    -H "Content-Type: application/json" \
    -d '{"query": "I modified the login flow", "top_k": 2}'

  # Generate advisory
  curl -X POST http://localhost:8000/advisory \
    -H "Content-Type: application/json" \
    -d '{
      "contributor_intent": "Adding OAuth2",
      "files_changed": ["src/auth.py"],
      "labels": ["security"]
    }'

  # View API documentation
  http://localhost:8000/docs

RUN TESTS
  python test_week1.py                    # Native tests
  bash verify_week1_docker.sh             # Docker tests (Unix)
  verify_week1_docker.bat                 # Docker tests (Windows)

TECHNICAL SPECIFICATIONS
================================================================================

EMBEDDING MODEL
- Name: all-MiniLM-L6-v2 (sentence-transformers)
- Dimension: 384-dim vectors
- Model Size: ~90MB
- Speed: ~100ms per query

CHUNKING STRATEGY
- Target Size: 400 tokens per chunk
- Overlap: 50 tokens between chunks
- Method: Section-aware (split on markdown headers)
- Chunks: ~200-300 total across 4 documents

VECTOR DATABASE
- System: ChromaDB
- Similarity: Cosine distance
- Persistence: On-disk storage
- Size: ~50-100MB per ingestion

RETRIEVAL PARAMETERS
- Default top_k: 3
- Similarity threshold: 0.6 (configurable)
- Multi-pass: Retrieves k*3, filters to top-k
- Quality score: Composite 0-1 normalized

SERVER SPECIFICATIONS
- Framework: FastAPI
- ASGI Server: Uvicorn
- Host: 0.0.0.0 (all interfaces)
- Port: 8000 (configurable)
- Workers: 1 (default, scalable)
- Async: Full async/await support

DOCKER SPECIFICATIONS
- Base Image: python:3.11-slim
- Model Caching: Layers optimized
- Health Check: /health endpoint
- Volumes: chroma_data for persistence
- Networks: Internal service communication
