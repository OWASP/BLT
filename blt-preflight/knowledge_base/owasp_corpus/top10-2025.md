# OWASP Top 10 2025

## Overview
The OWASP Top 10 2025 lists the most critical security risks to web applications.

## The Top 10 Risks

**A01:2025 — Broken Access Control**  
Users can act outside their intended permissions. Most common and severe risk.

**A02:2025 — Security Misconfiguration**  
Insecure default settings, unnecessary features, or improper configurations.

**A03:2025 — Software Supply Chain Failures**  
Vulnerabilities introduced through third-party components or pipelines.

**A04:2025 — Cryptographic Failures**  
Weak or misused cryptography leading to data exposure.

**A05:2025 — Injection**  
Untrusted input executed as commands (SQLi, XSS, Command Injection, etc.).

**A06:2025 — Insecure Design**  
Flaws in architecture or business logic that cannot be easily fixed in code.

**A07:2025 — Authentication Failures**  
Weak authentication, session management, or credential handling.

**A08:2025 — Software or Data Integrity Failures**  
Insecure deserialization, unsigned updates, or unverified code/data.

**A09:2025 — Security Logging & Alerting Failures**  
Insufficient logging and monitoring making attacks hard to detect.

**A10:2025 — Mishandling of Exceptional Conditions**  
Poor error handling leading to information leaks or unstable states.

## How to Prevent (General Guidance)

- Enforce **deny by default** access control
- Use parameterized queries and input validation
- Implement proper authentication + MFA
- Keep dependencies updated and verify supply chain
- Use strong, modern cryptography with proper key management
- Log security events and monitor for anomalies
- Fail securely on errors (never fail open)

## RAG Usage Notes
Each risk (A01–A10) should be treated as a separate retrieval unit during chunking.
