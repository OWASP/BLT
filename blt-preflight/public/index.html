01 / Advisory card

Authentication change detected

Use on pull requests when Preflight identifies a sensitive path or label.

Review session handling

src/auth/session.py

Critical

Confirm token rotation, expiration, and invalidation behavior before merging this authentication update.

Open OWASP guidance  →

Copy-paste snippet

<aside class="rounded-lg border border-red-200 bg-red-50 p-4
  dark:border-red-950 dark:bg-red-950/30">
  <span class="text-xs font-bold text-white bg-[#E10101]">
    Critical
  </span>
  <h3>Review session handling</h3>
  <p>Confirm token rotation and invalidation behavior.</p>
</aside>

Theme behavior: light mode uses a soft red warning surface; dark mode shifts to a subdued red tint with a low-contrast border.

02 / Local check

Contributor terminal prompt

Use in setup screens and documentation to make the local workflow easy to scan.

preflight / staged changes

$ pf

Scanning 3 staged files...

! authentication guidance found

Review: src/auth/session.py

Copy-paste snippet

<div class="rounded-lg bg-[#111827] font-mono text-xs text-slate-200">
  <p><span class="text-green-400">$</span> pf</p>
  <p class="text-slate-400">Scanning 3 staged files...</p>
  <p>! authentication guidance found</p>
</div>

Theme behavior: the terminal stays ink-dark in both modes for consistent code contrast; its outer border follows the active surface.

03 / Feedback form

Close the guidance loop

Use after an advisory to learn whether the recommendation helped the contributor.

Was the authentication guidance useful?

Copy-paste snippet

<fieldset>
  <legend class="text-sm font-bold">
    Was the authentication guidance useful?
  </legend>
  <label><input type="radio" name="helpful"> Yes, helpful</label>
  <label><input type="radio" name="helpful"> Needs work</label>
</fieldset>

Theme behavior: inputs use white surfaces and gray borders in light mode, then panel surfaces and subdued blue-gray borders in dark mode.
