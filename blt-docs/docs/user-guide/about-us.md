# About OWASP BLT

OWASP BLT is the OWASP Bug Logging Tool. It is an open source project focused on improving how bugs and security-related issues are reported, tracked, and coordinated.

## What BLT is

BLT provides a place for users to report issues they find and for maintainers or organizations to review activity around those reports. The project supports community participation, issue triage, and documentation for the BLT platform and related repositories.

Because BLT is an open source OWASP project, the platform and its documentation may evolve over time. Use these pages as workflow guidance for the documented BLT experience, and check the active deployment for the exact fields and options available.

## Who the documentation is for

- Users who want to understand the BLT web experience.
- Bug reporters who need help preparing clear issue reports.
- Organization or project maintainers who review reports and activity.
- Contributors who want to move from using BLT to helping maintain it.

## How to use the docs

Start with the user-guide pages when you want to complete a task in the BLT interface, such as signing in, reporting a bug, reviewing an issue, or browsing activity pages.

Use the contributor and developer pages when you want to help maintain the platform, understand repository-specific work, or contribute documentation and code.
