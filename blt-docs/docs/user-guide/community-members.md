# Community members

The community members page helps users find visible BLT contributors, maintainers, or participants. It is useful for learning who is active and opening related profiles.

## When to use this page

- You want to browse visible community members.
- You are looking for a contributor or maintainer profile.
- You want to understand community participation around BLT.
- You need to invite or coordinate with users where those features are enabled.

## Main actions

1. Open the community members page.
2. Browse the visible member list.
3. Use available search, filters, or pagination if shown.
4. Open a profile to review more detail about a specific user.
5. Use contact or invite features only where enabled and appropriate.

## What to check

- Profile and activity data should be used respectfully.
- Do not assume a user's role, availability, or authority from a listing alone.
- Avoid using member information for spam, harassment, or unrelated outreach.
- Confirm permissions before inviting users to organization or project workflows.
