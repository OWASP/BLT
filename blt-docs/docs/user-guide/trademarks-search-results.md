# Trademark search results

Trademark search results show records that match a submitted trademark query. The visible fields depend on the data source and the active deployment.

## When to use this page

- You have submitted a trademark search.
- You want to compare matching records.
- You need to refine a search term based on the results.
- You want to understand visible trademark names, owners, status values, or source fields where shown.

## Main actions

1. Review the result names and identifiers.
2. Check owner, status, source, date, or category fields if they are shown.
3. Open any available detail links for records that need closer review.
4. Return to the search page to refine the query if needed.
5. Record the source and date of any information you plan to reference elsewhere.

## What to check

- Similar names may not mean the same owner, category, or legal status.
- Status and source fields should be interpreted according to the source that provided them.
- Results are informational and are not legal advice.
- For legal or policy decisions, use qualified legal review and OWASP-provided policy resources.
