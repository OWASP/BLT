# Global leaderboard

The global leaderboard is an activity ranking view for BLT users. It can help users understand visible contribution activity across the platform.

## When to use this page

- You want to browse visible user rankings or contribution activity.
- You want to find active community members.
- You are comparing your activity with other visible profiles.
- You want a high-level signal of platform participation.

## Main actions

1. Open the global leaderboard page.
2. Review the visible ranking or activity columns.
3. Open a user profile if you need more context about a participant.
4. Use any available pagination, sorting, or filtering controls to continue browsing.

## What to check

- Rankings depend on the data and scoring model used by the active deployment.
- Treat leaderboard position as an activity signal, not as a guarantee of reward, status, or authority.
- Review profile details before making assumptions about a user's work.
- Use leaderboard data respectfully and avoid harassment or spam.
