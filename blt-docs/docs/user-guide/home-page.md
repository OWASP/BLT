# Home page

The BLT home page is the public entry point for the BLT web experience. It helps users understand recent activity, find common workflows, and decide where to go next.

## Purpose of the home page

The home page introduces the active BLT deployment and gives users a starting point for browsing reports, accessing account actions, or learning more about the project.

## What users can usually find there

- Entry points for signing in or creating an account.
- Links to report or browse issues.
- Navigation to community, company, statistics, or leaderboard pages.
- High-level information about BLT and current platform activity.

The exact layout can vary by deployment. Use the visible navigation and page labels as the source of truth for the current interface.

## Common next steps

1. Review the available navigation options.
2. Sign in if you need account-specific actions.
3. Open the bug reporting workflow when you are ready to submit an issue.
4. Browse leaderboards, statistics, companies, or community pages to understand current activity.
