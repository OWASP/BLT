# Weekly activity

Weekly activity views show recent contribution or platform activity over a weekly period. They help users, contributors, and maintainers scan what changed recently.

## When to use this page

- You want to review recent BLT activity.
- You are preparing for triage or community follow-up.
- You want to see visible contribution patterns for the week.
- You need a short-term view alongside broader statistics.

## Main actions

1. Open the weekly activity page.
2. Review the visible activity categories and time period.
3. Scan for active users, reports, comments, project work, or other fields shown by the deployment.
4. Open related issue, profile, or statistics pages for more detail.

## What to check

- Confirm the date range or weekly period represented.
- Treat activity counts as a current snapshot that may change as data updates.
- Maintainers can use the page to find follow-up needs, stale work, or high-activity areas.
- Contributors can use the page to understand recent community activity.
