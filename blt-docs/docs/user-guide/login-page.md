# Log in

Use the login page to access account-specific BLT pages and actions. Signing in may be required before you can report bugs, comment, manage profile details, or use maintainer workflows.

## When to use this page

- You already have a BLT account.
- You need to access pages that require authentication.
- You were redirected to login before completing another action.
- You want to confirm that your account credentials still work.

## Main actions

1. Open the login page from the site navigation or from an authentication prompt.
2. Enter your account credentials in the required fields.
3. Submit the login form.
4. Continue to the page or workflow you were trying to access.

## What to check

- Confirm that you entered the correct username or email, depending on the field shown.
- Confirm that the password is typed correctly.
- If login fails, read the validation message and correct the highlighted field.
- If you do not have an account, use the sign-up page.
- If password change or reset options are available, use the password page or the recovery option shown by the active deployment.
