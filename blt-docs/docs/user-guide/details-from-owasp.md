# OWASP BLT overview

OWASP BLT is an OWASP project centered on the Bug Logging Tool. From the OWASP project perspective, BLT supports community work around reporting, organizing, and improving issue handling.

## OWASP project context

OWASP projects are community-led efforts. BLT belongs in that ecosystem as an open source project with documentation, repositories, and contributor workflows.

The current state of the project should be checked from official OWASP and BLT project resources, because repository locations, maintainers, and platform behavior can change over time.

## How BLT supports community work

- It gives users a structured way to report issues.
- It gives maintainers and organizations a place to review report activity.
- It creates documentation paths for users, contributors, and developers.
- It provides a project context for community contribution and coordination.
