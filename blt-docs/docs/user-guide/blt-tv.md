# BLT TV

BLT TV is a media or community page when it is present in the product. Depending on the active deployment, it may contain videos, demos, community updates, project media, or related educational content.

## When to use this page

- You want to view BLT-related media or community updates.
- You are looking for demos or project information in video or media form.
- You want to share a media resource with another BLT user.
- The active deployment links to BLT TV from the navigation.

## Main actions

1. Open the BLT TV page from the navigation.
2. Review the available media entries.
3. Select the item you want to view.
4. Follow any visible links or controls provided by the active deployment.

## What to check

- Content and media sources can vary by deployment.
- Do not assume live streaming, a specific video provider, or archived recordings unless the page shows them.
- If content appears outdated, confirm current project information from the main BLT or OWASP project pages.
