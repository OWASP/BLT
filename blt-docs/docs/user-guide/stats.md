# Statistics

Statistics pages summarize BLT activity and platform data. Use them to understand broad trends rather than to make decisions from a single number.

## When to use this page

- You want a high-level view of BLT activity.
- You need context for reports, users, projects, organizations, or trends.
- You are preparing a triage or community update.
- You want to compare activity across time periods, where the view supports it.

## Main actions

1. Open the statistics page.
2. Review the available totals, charts, tables, or trend views.
3. Identify the time period and data category represented.
4. Compare statistics with issue, company, or activity pages when you need more context.

## What to check

- Statistics can depend on current data freshness and background processing.
- Categories may include reports, activity, projects, organizations, users, or trends depending on the deployment.
- Avoid treating aggregate numbers as a guarantee of current status for a specific issue.
- Open the related detailed page before taking action.
