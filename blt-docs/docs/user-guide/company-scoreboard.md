# Company scoreboard

The company scoreboard provides an organization-level view of visible BLT activity. It helps users and maintainers compare report activity, status, and engagement across organizations or companies.

## When to use this page

- You want to review organization-level activity.
- You are looking for companies with active reports.
- You need a starting point for triage or engagement.
- You want to compare visible status or activity indicators across organizations.

## Main actions

1. Open the company scoreboard page.
2. Review the organization names and visible activity or score fields.
3. Use available sorting, filtering, or pagination controls if shown.
4. Open a company page for more detail.
5. Use the information to guide triage, follow-up, or community engagement.

## What to check

- Confirm what each visible column means before comparing organizations.
- Treat scores and counts as current platform data, not a complete external assessment.
- Check the company dashboard before acting on a specific report or organization.
- Remember that data freshness can affect scoreboard values.
