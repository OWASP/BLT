# Change password

Use the password page when you need to update your BLT account credentials or recover access through the options available in the active deployment.

## When to use this page

- You want to replace an old or weak password.
- You believe your password may have been shared or exposed.
- You are prompted to update credentials before continuing.
- You cannot sign in and the deployment provides a password recovery flow.

## Main actions

1. If you are signed in, open the password or account settings page.
2. Enter the current password if the form asks for it.
3. Enter the new password and confirmation values requested by the form.
4. Submit the change.
5. If you are not signed in and a reset option is shown, follow the reset instructions provided by the active deployment.

## What to check

- Use a unique password that you do not reuse on other services.
- Do not share your password with other users, maintainers, or organizations.
- Confirm that the new password and confirmation fields match.
- After changing the password, sign out and sign back in if you want to confirm the new credentials work.
- Update any password manager entry you use for BLT.
