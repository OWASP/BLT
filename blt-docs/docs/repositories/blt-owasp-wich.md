# BLT-OWASP-Wich

BLT-OWASP-Wich is a supporting discovery, metadata, and community-oriented module in the BLT ecosystem.

## Current repository status

The current repository location should be confirmed with maintainers before opening new work. Historical GitHub links may exist in older documentation, but migration status should be verified before using them as the source of truth.

## Purpose

This module supports discovery or evaluation workflows around OWASP repositories and community project data. Avoid treating historical feature descriptions as current product guarantees until the owning repository confirms them.

## Best starting points

Contribute here when the work involves:

- Discovery workflows for OWASP or BLT-related repositories.
- Metadata review or classification support.
- Community-facing project information.
- Documentation that explains what the module checks, generates, or displays.

Before starting implementation work, confirm the current repository location and current feature scope with maintainers.

## Local development notes

Use the owning repository's README and configuration files for setup. Keep BLT-docs high-level unless a command is verified and maintainers want it duplicated here.

Do not include personal access tokens, API keys, or generated credentials in examples.

## Documentation notes

BLT-docs should describe ownership, purpose, and contribution boundaries. The module repository should own exact checks, scoring logic, scripts, workflows, and deployment details.
