# BLT-OWASP-Projects

BLT-OWASP-Projects is an OWASP project data and catalog support module.

## Current repository status

The current repository location should be confirmed with maintainers before opening new work. Historical GitHub links may exist in older documentation, but migration status should be verified before using them as the source of truth.

## Purpose

This module supports OWASP project catalog data, repository mappings, and project discovery workflows. It is useful when contributors need to understand or improve how OWASP project information is collected, reviewed, or presented to related BLT workflows.

## Best starting points

Contribute here when the work involves:

- OWASP project catalog data.
- Repository-to-project mappings.
- Generated project data files.
- Project discovery views or supporting dashboards.
- Documentation for catalog maintenance workflows.

Confirm whether the work belongs in this module, BLT-OWASP-metadata, or another supporting data repository before starting.

## Local development notes

Use the owning repository's README and workflow files for setup and data generation commands. Do not copy historical token setup or automation commands into BLT-docs unless maintainers confirm they are current.

Keep API tokens, Slack webhooks, and local environment files outside git.

## Documentation notes

BLT-docs should document how this module fits into the BLT platform and where contributors should begin. The module repository should own exact scripts, generated data formats, automation schedules, and dashboard implementation details.
