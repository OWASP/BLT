How it works

Time tracking without friction.

BLT Timer keeps the flow simple enough to use every day: start the session, describe the work, save it, and move on.

01

Start the timer

Begin a BLT work session with one click before you start coding, testing, reviewing, or writing.

02

Add context

Add a title, note, project, or reference so your log makes sense later.

03

Save your work

Stop the timer and save the session as a clean work log tied to your account.

04

Review progress

See today’s total, weekly time, and export logs whenever you need a status update.

Features

Built for focused contributor work.

The production app feels like a utility, not a project-management suite. These are the core pieces needed for a useful timer.

One-click timer

Start, pause, resume, and stop without leaving the page.

Custom local auth

Email or username login powered by the Python Worker.

Manual work logs

Title, notes, project, reference, start time, end time, and duration.

Daily and weekly summaries

Small totals that help contributors write updates.

Searchable history

Find previous sessions by title, project, or note.

CSV/JSON export

Take your logs into reports, notes, or spreadsheets.

Privacy

Private by design.

BLT Timer only stores the logs you choose to save. It does not track your keyboard, mouse, screenshots, code, Git provider activity, or AI prompts.

  • ✓Only manually saved account/session records and work logs are stored.
  • ✓No screenshots, keystroke capture, mouse tracking, or productivity scoring.
  • ✓No GitHub/GitLab OAuth requirement; the app uses custom local auth.
  • ✓Logs can be exported as CSV or JSON for your own reporting.
