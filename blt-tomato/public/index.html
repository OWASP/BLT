Fund OWASP projects

BLT Tomato is an OWASP BLT project that helps other OWASP projects. It lists every project that publishes a FUNDING.yml, with each way to support it: the project's own funding links, and the contributors who take GitHub Sponsors.

⚠

OWASP no longer collects donations for individual projects

Many projects still list an owasp.org/donate link in their FUNDING.yml. Those links support the OWASP Foundation as a whole, not the project named in them. To fund a particular project, use the project's own links below or sponsor the people who build it on GitHub Sponsors.

Maintainers: point your FUNDING.yml at your own GitHub Sponsors, Open Collective or other page, and this list picks it up within a week.
