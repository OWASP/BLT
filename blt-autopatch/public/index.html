BLT Autopatch

A home for transparent, reviewable security patch automation in the OWASP BLT ecosystem.

Source code Open issues All BLT projects

Status

Early-stage project. The repository and deployment foundation are ready; production patching behavior is not yet implemented.

Repository

Ready The blt-autopatch folder lives in the OWASP BLT monorepo.

Deployment

Ready This page is served as static assets by the blt-autopatch Worker at autopatch.owaspblt.org.

Patching

Not started No patching behavior is implemented yet.

The goal

Security patch automation that people can see into and sign off on.

Transparent

Patch automation that is open about what it changes, in the open-source OWASP BLT ecosystem.

Reviewable

Patches that are proposed for review rather than applied silently.

Develop

The folder holds the landing page (public/index.html) and the Worker configuration (wrangler.toml). Preview and deploy it with Wrangler.

Preview locally

git clone https://git.owaspblt.org/BLT.git
cd BLT/blt-autopatch
npx wrangler dev

wrangler.toml

name = "blt-autopatch"

[assets]
directory = "./public"

[[routes]]
pattern = "autopatch.owaspblt.org"
custom_domain = true
