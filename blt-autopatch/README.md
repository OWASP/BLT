# BLT-Autopatch

**Source Code:** [https://git.owaspblt.org/BLT/BLT-Autopatch](https://git.owaspblt.org/BLT/BLT-Autopatch)

A home for transparent, reviewable security patch automation in the OWASP BLT ecosystem.

This is an early-stage project. The folder holds the landing page only: [`public/index.html`](public/index.html) is
served as static assets by the `blt-autopatch` Worker ([`wrangler.toml`](wrangler.toml)) at
[autopatch.owaspblt.org](https://autopatch.owaspblt.org). No patching behavior is implemented yet.
